# Deep Learning

A structured repository documenting my journey of learning and implementing **Deep Learning** concepts from fundamentals to practical neural network applications.

The goal of this repository is to build a strong understanding of how deep learning models work **from mathematical foundations to implementation**, rather than relying only on high-level frameworks.

## 📚 Topics Covered

* Machine Learning Foundations
* Perceptron
* Loss Functions
* Hinge Loss
* Gradient Descent
* Neural Networks
* Forward Propagation
* Backpropagation
* Activation Functions
* Optimization
* Convolutional Neural Networks (CNNs)
* Recurrent Neural Networks (RNNs)
* CNN-LSTM Architectures
* Model Training & Evaluation

## 🛠️ Tools & Technologies

* **Python**
* **NumPy**
* **Pandas**
* **Matplotlib**
* **Scikit-learn**
* **TensorFlow / Keras**
* **Jupyter Notebook**
* **Google Colab**

## 🎯 Learning Approach

Each topic is explored through:

1. **Conceptual understanding**
2. **Mathematical intuition**
3. **Implementation from scratch**
4. **Visualization and experimentation**
5. **Framework-based implementation**
6. **Practical applications**

Whenever possible, algorithms are implemented from scratch before using high-level libraries.

## 📌 Purpose

This repository serves as my **learning log, experimentation space, and reference** while developing deeper expertise in Deep Learning and Artificial Intelligence.

New implementations, experiments, and projects will be added continuously.
